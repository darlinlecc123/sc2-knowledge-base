# 多模型评测图形 QA 记录

## 图形契约

- 核心结论：优化后的 RAG 在 DeepSeek v4 Flash 上表现出明显的准确率—Token 优势，但唯一首次盲测仍未通过全部冻结门槛。
- 图形类型：quantitative grid。
- 后端：Python / matplotlib，全流程不混用 R。
- 最终宽度：约 183 mm 双栏宽度；按面板信息量设置高度。
- 输出：SVG 可编辑文字、PDF、600 dpi PNG。
- 主证据：同题集跨模型比较、优化后 v0.6 三条件比较、首次盲测门槛。
- 审稿风险：模型身份由中转站声明、模型配置不完全一致、单次运行无置信区间、不同 challenge 版本不可直接横比。

## 数据完整性

- 使用源 JSON 中全部相关条件与核心指标，没有删除模型、条件或不利结果。
- v0.3 多模型数据包含 2 个模型乘 3 个条件；v0.6 三条件包含全部 3 个条件；首次盲测包含全部 6 个冻结指标。
- 不从逐题数据重新定义官方指标，图表直接使用已验收的 summary 和 audit 字段。
- 费用字段为空，因此未绘制美元成本。

## 统计说明

- challenge v0.3：n = 41 道题；challenge v0.6：n = 60 道题。
- 每个条件是一次固定题集运行，不是独立随机重复；没有可用标准差、置信区间或显著性检验。
- 图中数值是评测汇总，不绘制误差条。

## 视觉 QA 要点

- 白色背景，无彩虹色图；最新版三条件图中 RAG 使用唯一强调色。
- SVG 文字保持可编辑，PDF 使用 TrueType 字体。
- Token 和延迟跨数量级，统一采用对数坐标并在轴标签中说明。
- PNG 用于 Markdown 预览；SVG/PDF 用于后续编辑和印刷。
- 图内采用简短英文标签以避免高密度中文拥挤；报告正文和图注提供完整中文解释。
